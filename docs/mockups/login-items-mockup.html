决策要点

原型说明（v1.5 方案）

  • 侧边栏第 4 项：Login Items，与三类 launchd 并列
  • 列表来自 BTM（dumpbtm），展示类型、Disposition、路径
  • 与 launchd 重复项显示黄色徽章「已在 LaunchDaemons」
  • 有 plist：载入 / 移除（复用 bootstrap/bootout）
  • 无 plist 或需用户授权：仅「打开登录项设置」
  • 不做：在应用内直接切换 BTM 开关（无公开 API）
