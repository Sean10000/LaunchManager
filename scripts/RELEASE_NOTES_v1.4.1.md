## LaunchManager v1.4.1

### Fixes
- **Localization:**「载入」「移除」and the delete confirmation message now show in English on English macOS (were missing from the String Catalog since v1.4.0).

### Installation

```bash
brew tap Sean10000/tap
brew upgrade --cask launchmanager
```

Or download **LaunchManager.dmg** below and drag to Applications.

> First launch: right-click → Open (app is not notarized).
